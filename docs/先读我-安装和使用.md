# Agnes 女仆伙伴 · 独立安装包

这是可移到其他 Minecraft 实例使用的独立版本，不要求“逆转未来”整合包。首次需要填写自己的 Agnes API Key，保存一次后复用，不读取旧联机向导或旧版 Agnes 配置中的密钥。

## 运行条件

- Minecraft **1.20.1**，使用 **Forge 47.x**；推荐已测试的 **47.4.18**。
- Java **17**。Forge 和 Java 由启动器安装；它们不是丢进 mods 的前置 JAR。
- 车万女仆 **1.5.3 Forge / MC 1.20.1**，本包已附带。
- 可用的 Agnes API Key 和访问 Agnes 接口的网络。

不是 Fabric、NeoForge 或其他 Minecraft 版本的通用包。“都是 1.20.1 Forge”满足基础平台要求，但不能保证与任意其他模组、核心修改、保护插件或女仆附属都兼容。当前测试针对 Forge 47.4.18 和包内车万女仆 1.5.3。

这份车万女仆本体的依赖清单只要求 Minecraft 和 Forge，不需要另加 GeckoLib、Curios、Cloth Config 等前置。爱恋、史诗战斗女仆附属、女仆实用任务、MaidReform 都不是本包必需项；不装某个附属，就没有那个附属提供的原生任务。

## 安装

1. 关闭目标游戏，在启动器里打开该 **1.20.1 Forge 实例的游戏文件夹**。开启版本隔离时，使用这个版本自己的文件夹。
2. 将 `安装用-mods` 中的当前 **Agnes JAR** 放入目标游戏的 `mods` 文件夹；车万女仆本体请使用包外已安装的 1.5.3 Forge 版。
3. 已有车万女仆时不要重复放第二份，使用本包的 1.5.3 或确认现有版本相符。已有 `agnespartner` 模组时先移出旧版，只保留本包的独立版。
4. 启动游戏。

`安装用-mods` 里的 `agnespartner-1.0.44-portable.jar` 就是当前推荐版本：它只从本实例的 `config/agnespartner-portable.toml` 读取密钥。Promaid 1.3.0 可与它一起安装；两者采用协作模式，Promaid 不会取消 Agnes 的采集或挖掘。`现用版本备份-不要一起安装` 存放早期版本，仅供回退，**不要和当前版本一起安装**：它们使用同一个模组 ID。

## 第一次填写 API

在游戏主菜单打开 **模组 / Mods → Agnes AI Partner → 配置 / Config**。

填写自己的 API Key，模型默认 `agnes-2.5-flash`，按需要保留“发送游戏画面：开启”，点击 **保存并返回**。密钥输入会显示为星号；不用在聊天框输入，也不用启动 PowerShell 或旧联机脚本。现在即使按 Esc 关闭，只要填写内容格式有效也会自动保存；“取消”才会放弃本次修改。

可选填写智谱 API Key 和模型（默认 `GLM-4.6V-Flash`，支持视觉），打开“Agnes 失败时使用智谱”。当 Agnes 请求超时、HTTP 错误或返回格式异常时，模组会把同一轮请求自动改发到智谱 OpenAI 兼容接口；没有填写智谱 Key 时不会调用智谱。免费额度和可用模型以智谱账号页面为准。

还可以填写一个通用 OpenAI 兼容备用接口：完整的 API 地址（例如 `https://api.openai.com/v1/chat/completions`）、可选 API Key，以及模型名称，打开“前两者失败时启用通用备用”。只有 Agnes 和智谱都失败后才会请求这个地址。模型名称留空时不会调用；本地兼容服务可以不填 Key。接口必须接受标准 Chat Completions JSON 请求，具体模型、额度和鉴权方式以服务商说明为准。

保存位置为目标游戏目录下的：

```text
config/agnespartner-portable.toml
```

此独立版只从这个文件读取 API 和模型，不读取旧的 `agnespartner-common.toml`，也不读取系统 `MinecraftAIPartner/config.json`。关闭再开游戏仍会复用已保存的配置，换到全新游戏目录才需要重新填写。

如果某个启动器不显示配置按钮：先运行一次游戏并退出，用文本编辑器打开上述文件，在 `apiKey = ""` 的引号中填写自己的密钥，保存后重新启动。`首次配置模板` 提供空白示例；**不要用空白模板覆盖已经设置好的配置**。

配置以本机普通文本保存。要把安装包给别人，请分享这份未填写密钥的文件夹，不要连同你之后生成的个人配置或截图缓存一起分享。

## 绑定和日常使用

先按车万女仆本体的方式获得并驯服自己的女仆；本模组不会凭空创建一只已经驯服的女仆。靠近并看向她，在聊天框输入：

```text
/aipartner maid bind
/aipartner autonomy on
```

绑定随存档保存，同一只女仆不用每次重绑。以后普通聊天会得到回应；让她站起来、保持清醒，结束战斗后即可自主活动。

| 操作 | 用法 |
| --- | --- |
| 普通对话 | 直接在聊天框输入文字，她的回答出现在头顶气泡里 |
| 自主活动 | `/aipartner autonomy on` |
| 停止自主并跟随 | `/aipartner autonomy off` |
| 看当前计划、执行结果、视觉、建房进度 | `/aipartner status` |
| 看心情、亲密度、她对你的称呼 | `/aipartner maid personality` |
| 看她此刻"看到"了什么（本地，不花接口费） | `/aipartner maid sight` |
| 看她记住了哪些地方 | `/aipartner maid landmarks` |
| 测试气泡是否显示 | `/aipartner maid speak` |
| 查看女仆背包 | `/aipartner inventory` |
| 解除绑定 | `/aipartner maid unbind` |
| 围棋 / 五子棋选择 | 靠近自己的女仆，输入 `/aipartner go` |

可以直接说：“你自己按生存需要找材料、做工具；缺材料就看看附近箱子和木桶，条件合适时盖一间小屋。”

不要使用 `/aipartner summon` 来代替女仆绑定；那是保留的旧独立伙伴实体，功能与女仆不同。

## 她会自己说话、自己找事做

1.0.4 起，她的对话和想法都显示为**车万女仆原生气泡**：说出的话是普通对话气泡，正在盘算的事情是原生的思考气泡。行动结果仍然单独显示在物品栏上方，不会和她的话混在一起。

主动开口由本地判断，**不需要联网**：你回到存档、天亮入夜、受伤、附近有敌人、你没食物、下雨、她空闲太久等时机都会说一句，同一句不会重复，你刚说过话时不会插嘴。想让她安静，直接说「先别主动说话」「安静一点」「别说话」；想恢复就说「可以主动聊天了」「多陪我聊聊」。

两次规划之间的空档，她不会擅自切换原生闲逛任务；移动和生存行动由 Agnes 的规划控制。农田只有在真实可收获或可播种时才会提供给 Agnes 选择，不会被空闲兜底反复接管。

这些行为都只在**自主活动开启**、她确实空闲、没有战斗或受伤、也没有你刚下达的安排时生效；你手动改任务、坐下、战斗、睡觉、修整时都会立刻让位。细节和全部触发时机见 `详细说明/女仆自然行为与气泡说明.md`。

## 已有功能和范围

- **三种定型蓝图（1.0.8）**：5×5 小屋（约 78 块＋1 门 1 火把）、带储物间的 7×7 石屋（约 175 块＋1 门 2 火把，里间能放箱子和熔炉）、围栏菜园（约 20 栅栏＋16 耕地，只在背包有耕地时才建）。都用场地 ID 前缀选蓝图，材料开工前核算，中断可续建，完工记成地标。**仍是固定图纸，不能自由设计。**
- **主动猎杀（1.0.7）**：会主动去打野生的、未命名、未驯服的动物换肉，真实攻击力扣血、原版掉落表进包；食物少于 6 份时打猎优先于摘浆果和钓鱼。绝不碰你的宠物、命名过的动物和其他女仆。
- **安全阶梯下矿（1.0.7）**：朝面向方向一次挖一格台阶往下（4～24 格，默认 12），挖过的台阶就是回程路；**每一步开挖前都会检查，遇到水或岩浆立刻停止并走回地面**，沙砾等会塌的方块也会停；每 6 格放一支火把，挖完在井口记一个矿点地标。不会顺着矿脉横挖，不会挖到基岩。
- **地标记忆（1.0.6）**：她会把**自己真正做过事**的地方记进存档——挖过的矿、摘过的浆果丛、盖好的小屋、自己放的工作台和熔炉，以及扫描时真正看到的水域。下次需要时按记忆直接走过去（不需要重新观察），到达后核对那里还在不在；连续两次对不上就自动忘掉，不会反复跑去空地方。最多记 24 处，按维度分开。见 `/aipartner maid landmarks`。
- **视觉闭环（1.0.5）**：每轮决策前尽量补拍一张新画面（画面过旧会自动再拍），并把「她眼前看到什么」做成机器可读清单一起交给 Agnes：正前方是什么、距离、能不能走到、可采集的话直接给出目标 ID。她还能自己 `look` 转头看清某样东西、`scan_area` 环视一圈；被地形或目标拒绝时约 45 秒就重看一次再决定，而不是干等下一次规划。
- **气泡对话与自主节奏**：说出来的话和心里盘算的事情都走车万女仆原生气泡，主动开口由本地判断（断网也会说话）；两次规划之间的空档会自己接手能启动的原生工作，条件齐了会自己走到远处落脚并安顿生活。详见《女仆自然行为与气泡说明》。
- **自主生存**：画面＋女仆状态交给 Agnes，Agnes 安排步骤，女仆实际执行并反馈。自主请求默认至少间隔 30 秒（可在配置中调整）；每轮最多八种步骤、十六次动作，期间持续执行，失败会停止剩余步骤。
- **基础操作**：原木和成熟浆果采集，露出空气面的石料/煤/铁矿采集，合成、换装，放工作台/熔炉/火把，真实熔炉烧炼，以及已安装女仆任务的切换。材料、工具耐久真实消耗。
- **仓库**：发现原版普通箱子、大箱子和木桶，走到四格内并可见后读取普通物品库存，再按需存取；不读取玩家背包，不访问锁住/受保护的容器、末影箱、未开宝箱或模组机器。
- **建房**：固定蓝图的 5×5 小屋，需要 80 个同种受支持的木板或石材、1 扇橡木门和 1 根火把，以及附近平坦空地。实际走近逐块建造，中断后可续建；不是任意设计建筑。
- **救援**：普通致死伤害进入待救援状态，主人四格内右键并保持距离和视线五秒可复苏；同主人的健康空闲女仆可尝试互救。无需 MaidReform；虚空和 `/kill` 不拦截。
- **棋类**：围棋和五子棋共用弹出界面、分别保存。空手、不按 Shift，右键原五子棋桌可选择棋类；Shift＋右键保留原桌操作。下棋不需要调用 Agnes API。

观察范围为水平百格内已加载区域，活动范围约离主人 128 格，不强制加载远处区块。坐下、睡觉、战斗、救援、手动安排、主人离线等情况会打断或暂停世界行动。

绑定女仆的视觉取自**女仆自己的眼睛位置和头部朝向**，后台独立渲染，不显示到玩家窗口。宽 640 像素，约每 15 秒刷新，请求前尽量补拍；图片在内存中使用，不跨存档复用。缺少有效画面或接口拒绝图片时会改用游戏状态，并在状态里说明。只拍客户端已加载的地形；启用光影包或“极佳”画质时暂停独立摄像头，关闭光影并选择流畅/高品质后恢复。详细限制与验证方法见 `详细说明/女仆独立视觉说明.md`。旧独立伙伴实体仍沿用玩家截图，缓存位于本实例 `agnespartner-cache`。

Agnes 只能调用已实现的动作，不能保证理解所有模组、任意操作机器、自由设计房屋或自主通关。不同地形、模型决策和其他模组的规则会影响实际完成情况。

## 单机与服务器

推荐先在单机本地存档使用。通过同一实例打开局域网时，主机负责 AI 请求；客户端和服务器须装兼容版本的模组。

专用服务器需要服务端和客户端都安装相关模组，**API 配置须填写在服务器的 config 目录**；客户端设置按钮只写客户端自己的文件，不会把密钥上传到服务器。当前没有把每个远程玩家的画面传到专用服务器的通道，因此远程服主要依据游戏状态，不具备本地单机的截图反馈能力。未验证所有专用服务器和多人组合。
