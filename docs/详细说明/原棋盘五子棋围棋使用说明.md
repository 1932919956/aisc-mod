# 在车万女仆原有棋盘上玩

本功能使用车万女仆放置的**原有 15×15 实体棋盘**。不会创建新的 GUI 棋盘，也不会另放一个棋盘。

1. 空手右键原棋盘任意格，打开模式菜单。
2. 选择“围棋 · 15 路 / 续局”或“五子棋 · 原棋盘 / 续局”。模式选择后回到世界。
3. 围棋：空手右键棋盘交叉点落子，黑方是玩家，白方是女仆；女仆落子后会把棋子直接显示在原棋盘上。双方各自停手后，在棋盘上点击死子，再用 Shift＋右键打开菜单确认计分。
4. 五子棋：保留车万女仆原本的规则、棋子、女仆 AI 和实体棋盘。选择五子棋后不要打开新 GUI，直接按车万女仆原本方式在棋盘上玩。
5. Shift＋右键原棋盘可重新打开菜单；棋局按棋盘位置保存，切换模式会保存另一种棋局，不会清除它。

女仆需要在棋盘附近，并且不能处于战斗、睡眠、倒地救援状态。离开菜单不会弃局。旧版弹出的独立 GUI 棋盘已经不再作为车万女仆实体棋盘的入口。
