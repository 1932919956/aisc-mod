# 女仆的 Agnes 原版生存循环

> 独立安装包说明：API 请在模组列表的配置界面填写一次，使用 agnespartner-portable.toml；下文旧版密钥复用和本机安装记录不适用。安装及兼容要求以根目录《先读我-安装和使用》为准。


后续已增加原版箱子/木桶存取和固定蓝图小屋建造，最新功能、限制与安装记录见《建房与仓库使用说明》。下文是基础生存版本的历史说明。

2026-09-20，适用于 Minecraft 1.20.1 / Forge 47.4.18 / 车万女仆 1.5.3。

## 怎么开始

完全退出并重启整合包，沿用已有女仆绑定和 Agnes 密钥。在聊天框输入一次：

```text
/aipartner autonomy on
```

让女仆处于站立、清醒且没有战斗目标的状态。正常情况下约十秒后开始尝试规划，之后自主请求至少间隔两分钟。没有近处可用资源时，她可能需要等待百格扫描或寻找其他地点。

可以正常聊天：“你把自己当成生存玩家，先解决吃的和工具，做完再决定下一步。” 不需要每一步发指令。`/aipartner status` 显示当前目标、实际结果、连续计划、烧炼情况和本轮视觉使用情况。

## 这次补齐的执行能力

画面和女仆数据交给 Agnes，由 Agnes 安排接下来的短期生存步骤。一次最多八种步骤、合计十六次动作；例如三次制作木板，再做工作台和木棍、放工作台、制作并装备木镐。执行器每次重新检查实际材料和目标，没有收到模型计划时不会凭空编造下一步。

可执行的基础链条是：木材 → 木板、木棍和工作台 → 木镐 → 石料和石器 → 熔炉 → 粗铁烧炼、铁器。食物可以采成熟甜浆果，或按条件使用女仆已有的种田、钓鱼等任务；已有可烧食材可以放入熔炉。生命、吃东西、拾取和战斗仍结合女仆原有机制，不是把实体改造成拥有完整玩家饥饿系统的真人玩家。

- 原木、浆果、石头、深板岩、煤矿和铁矿都需要先走近再实际采集。镐等级不足时不能开挖，挖掘会消耗耐久。矿物要求露出空气面，不支持自主挖地下隧道。
- 放置仅支持背包内真实的工作台、熔炉和火把；在身边寻找可见的平整空位，物品实际消耗。
- 普通配方使用自己的背包材料。超过 2×2 的合成要求四格内有可见工作台。
- 烧炼使用自己放置的空熔炉，每次投入一份材料和一份煤、木炭或木板，等待原版熔炉完成后取回；已有余热仍由原版处理，未消耗的燃料可收回。不加速熔炉，不读取其他玩家炉内库存。
- 不从玩家背包或箱子自动取料；材料缺失、保护事件拒绝、找不到路或工具损坏时停止剩余步骤，将原因交给下一轮 Agnes。

保持原来的百格分批扫描和已加载区块限制，活动范围为离主人约 128 格。每种资源选择附近的实际候选，不把图片中猜到的坐标直接变成挖掘指令。筛选不能完全识别玩家建筑里的原版石块；自主模式会真实改变允许采集的方块。

## 反馈、打断和视觉

每个小步骤完成后可直接接着执行本轮计划，无须等待下一次网络请求。失败就结束该计划，不会接着假装合成或装备成功。整条计划最多五分钟，寻路卡住约十五秒会停止；原有采集最长两分钟。新一轮 Agnes 收到实际库存、最近执行记录和未执行原因。

普通闲聊保留工作。明确让她跟随或做另一件事、坐下、睡眠、战斗、倒地救援、超出活动距离、传送、退出游戏或关闭自主模式时，会停止或使旧计划失效。烧炼中断时，已经投入的物品保留在熔炉，状态给出位置，不会复制返回背包。

```text
/aipartner autonomy off
```

此命令停止自主安排并恢复跟随，仍可聊天。

视觉使用玩家当前游戏画面，**不是女仆独立的第一人称摄像头**；提示明确给出这个区别，同时提供女仆自己的坐标、生命、装备、背包、时间和资源候选。画面不新鲜、视觉关闭或接口拒绝图片时，使用游戏状态继续，状态中如实显示降级情况。

## 能力和验证边界

这是基础生存行动闭环，不保证 Agnes 总能选对步骤或找到路，也没有加入末影龙通关、复杂机器或自由造房子。模型只有文字承诺而没有可执行行动时，会记录为“未执行”，不会播报已经做完。

验证使用 Forge 游戏测试里的真实女仆、实际方块和熔炉，并模拟 Agnes 返回的结构化计划；没有用付费 API 测试长期自主决策，也没有在完整整合包内进行长时间生存或帧率实测。

最终版本通过全部 22 项 Forge 游戏测试、419 项棋类规则断言和正式构建。正式 JAR 已检查包含新生存执行类，未包含测试类或车万女仆本体。
