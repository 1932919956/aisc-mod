# 在车万女仆原有棋盘上下围棋和五子棋

本版本不创建新的棋盘界面。围棋和五子棋共用车万女仆原本放置的 15×15 实体棋盘，棋子直接由车万女仆原生棋盘渲染。

## 开始

1. 空手右键原五子棋实体棋盘任意一格，打开“原棋盘 · 模式与对局”。
2. 选择“围棋 · 15 路 / 续局”或“五子棋 · 原棋盘 / 续局”。选择后菜单关闭，回到世界中的这张棋盘。
3. 也可以输入 `/aipartner go`，前提是你正看着 6 格内的原棋盘。
4. Shift＋右键棋盘可再次打开模式菜单。围棋棋谱书也只作为入口，不会创建另一张桌子。

女仆必须是你的女仆、在棋盘附近，并且没有战斗、睡眠、骑乘、倒地或救援状态。优先使用坐在这张桌旁的女仆。

## 围棋

- 玩家执黑先行，女仆执白。空手右键棋盘交叉点落子；女仆思考后，白子直接出现在原棋盘上。
- 使用 15×15 交叉点，支持提子、禁自杀、全局同形禁着和停一手。
- 双方连续停手后，回到棋盘点击死子整组标记，再 Shift＋右键打开菜单确认计分；不确定时选择继续落子。
- 围棋棋局按这张棋盘的位置保存，退出存档后可以继续。围棋不调用 Agnes API。

## 五子棋

选择五子棋后恢复车万女仆原本的五子棋规则、棋子显示、女仆 AI 和棋盘交互。不要打开附属 GUI；直接按车万女仆原本方式在世界棋盘上落子。

切换到围棋前会保存原五子棋棋局；切回五子棋会恢复它。两种棋局互不覆盖。

## 和 Agnes 生存逻辑的关系

开始实体棋盘对局会暂停女仆的采集、建造和自主规划；离开菜单或结束对局后恢复。聊天、视觉和 API 密钥不会被棋局改变。

当前棋盘功能已经完成纯 Java 15×15 围棋状态回放检查；实际客户端建议在安全地点试下一手，避免女仆正在战斗或救援时强行开局。
