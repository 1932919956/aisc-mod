# Agnes 与 Promaid 兼容说明

## 功能对照

Agnes 已覆盖 Promaid 的一部分核心能力：

- Agnes AI 请求、备用模型、视觉输入和自主规划
- 原生 TLM Agent 的状态查询与 Agnes 指令桥
- 采集、阶梯挖掘、合成、熔炼、放置、固定蓝图建造
- 狩猎野生动物、记忆、地标、视野扫描
- 普通箱子/木桶的存取和背包不足时自动存储
- 跟随、停留、探索、任务切换以及主人绑定/救援

Promaid 仍有 Agnes 没有完整移植的能力：

- 鞘翅空袭、扫帚飞行和巡逻航图
- 载具/坐骑驾驶、武装拴绳和飞行载具战斗
- 压缩盒、酿造任务、自动换武器和完整的自动战斗分类
- 排班表、指标石、Promaid 手册、复杂蓝图导入和设计器
- Promaid 的长期记忆索引、情绪/主动对话/TTS 等完整社交层

## 1.0.51 协作增强

- Agnes 的状态快照会标记 Promaid 是否已加载、当前是否处于 `maid_smart` 原生任务、自保状态、工作区域和溢出仓储开关，规划时会避开重复安排这些工作。
- Agnes 选择原生战斗任务时优先调用 Promaid 的战斗预检和模组武器识别；Promaid 不存在或接口变化时自动回退到车万女仆原生逻辑。
- Promaid 原生任务运行期间不再被 Agnes 误判成玩家手动模式，也不会被下一轮规划抢走导航；任务回到待命后才继续 Agnes 规划。
- 自动换装、持灯、补种、自保逃生、仓储溢出和跨维度跟随仍由 Promaid 自己的事件系统运行。Agnes 只负责生存目标、采集、阶梯竖井和固定建造，避免两个控制器同时改路。

## 一起安装时的行为

两边都会给同一只 TLM 女仆注册任务和移动控制器，直接同时运行会产生“一个系统刚让她走，另一个系统又改目标”的冲突。因此 Agnes 从 `1.0.35` 起会检测 `promaid`：

- 未安装 Promaid：Agnes 按自己的自主模式工作。
- 安装 Promaid 后采用协作模式：Promaid 保留自保、自动装备、灯光、手册、蓝图等独立增强功能，Agnes 继续负责生存规划、采集、建造、狩猎和阶梯竖井。
- 旧版 `yieldToPromaid` 配置字段仍能读取，但不再以全量让位方式清空 Agnes 动作，避免采集或挖掘被取消。

查看状态：`/aipartner status`。状态中会显示是否检测到 Promaid，以及当前协作模式。

这不是把 Promaid 源码复制进 Agnes，而是软兼容；Promaid 的 JAR 仍需用户自行安装并与当前 Forge/TLM 版本匹配。
