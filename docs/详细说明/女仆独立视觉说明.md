# 女仆自己的第一人称视觉

绑定的车万女仆现使用**她的眼睛位置和头部朝向**生成画面，不再把玩家截图作为女仆视觉。Agnes 同时获得拍摄位置、朝向、维度、截图年龄，以及女仆当前背包、生命、环境目标与上一步执行结果。

## 怎么使用

1. 完全退出并重新启动 Minecraft，进入本机单人存档。
2. 已经绑定过的女仆不用重绑，原整合包的 API 密钥继续复用。独立安装包仍需在第一次使用时填写自己的密钥。
3. 保持配置中的 `visionEnabled = true`。模型默认 `agnes-2.5-flash`。
4. 输入 `/aipartner status`，查看“摄像头”和“上次视觉请求”。摄像头显示“女仆独立视角已就绪”表示成功拍摄；“本轮已发送女仆第一人称画面＋游戏状态”表示该轮请求附带了图片。此状态不等于模型一定正确理解了图片。

## 拍摄与性能

- 后台使用独立画面缓冲区渲染，不把女仆画面显示到玩家窗口；正常玩家画面会紧接着绘制。
- 图片宽 640 像素、70 度垂直视野，约每 15 秒刷新。聊天/自主规划请求前会尽量补拍最新画面，最多等待 1.5 秒；连拍间隔至少 2 秒。
- 无玩家 HUD、手持物、准星或聊天框。图片在后台线程压缩，直接放在本次游戏的内存中，不跨存档复用。
- 女仆传送/跨维度、重新绑定、退出存档以及图片过期时，失效图片不会交给 Agnes。拍摄位置与女仆当前位置相差超过 4 格也会拒绝。
- 不是持续视频。额外渲染和 GPU 读回有开销，低配置机器仍可能出现短暂帧耗时增加；关闭 `visionEnabled` 可停用。

## 兼容与范围

- 当前女仆摄像头用于**本机单人存档的玩家本人所绑定的女仆**。开启局域网后主机玩家仍可用。远程玩家和专用服务器没有截图传输通道，使用游戏状态规划。
- Oculus 可以保留，但启用光影包或“极佳/Fabulous”画质时，独立摄像头会暂停。关闭光影并选“流畅/Fast”或“高品质/Fancy”，等待下一次拍摄会自动恢复。
- 遇到其他渲染兼容异常，会记录日志并在本次进入世界时停用摄像头；女仆继续依据游戏状态行动。修复渲染配置后重新进入存档。
- 只拍到玩家客户端已加载的地形、当前女仆视野内可见的部分，不会透视墙壁，也不会加载远方区块。她转身后视线会改变。
- 100 格游戏数据调查仍是另一种环境信息，不等于相机能看穿 100 格内的一切。Agnes 只能选择已经实现的行动，图片不能增加任意机器操作、任意建筑或自动通关能力。
- 旧版独立的 `Agnes伙伴` 实体仍沿用玩家截图；以上独立摄像头针对绑定的车万女仆。

## 画面不可用时

界面打开、世界暂停、女仆实体尚未在客户端加载、光影冲突或 API 拒绝图片时，会退回女仆游戏状态，并在状态中注明。不会把玩家画面冒充成女仆画面。关闭视觉只停止发图片，不影响状态驱动的生存、聊天、救援和下棋。
